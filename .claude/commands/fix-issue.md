# Fix Issue Command

## Workflow
1. **Analyze**: Read the issue description, stack trace, and relevant source files.
2. **Reproduce**: Locate or write an automated reproduction test.
3. **Fix**: Implement the minimal, clean solution addressing the root cause.
4. **Verify**: Run the test suite to ensure the fix passes without regressions.
