# Project Guidelines

## Overview
This file contains project-specific instructions and conventions that guide Claude's behavior in this repository.

## Common Commands
- **Build**: `npm run build`
- **Test**: `npm test`
- **Lint**: `npm run lint`

## Architecture & Code Style
- Follow clean code and modular design principles.
- Keep components focused and single-purpose.
- Ensure all business logic is covered by unit tests.
